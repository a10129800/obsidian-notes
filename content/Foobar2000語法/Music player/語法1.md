</center>
<span style="font-size: 15px; font-weight: bold; color: #ff5733;">變數初始化：</span><br>

* let：JavaScript 用來宣告變數的關鍵字。
* all_tracks：變數名稱，直譯就是「所有曲目」。
* null：目前沒有任何值。

1. 代表意義：宣告並初始化一個全域變數 all_tracks，預設值為 null。
2. 用途：在後續的腳本中，這個變數通常用來儲存播放清單（Playlist）中的所有音軌資料或物件，以便進行快取或批次處理。

* 這裡的 null 不代表「有 0 首歌」，而是比較接近：「現在還沒有取得 / 指定曲目資料。」

<span style="font-size: 20px; font-weight: bold; color: #ff5733;">解析：</span><br>

```
let font_title = gdi.Font("Microsoft JhengHei", 18, 1);
```
</center>

<span style="font-size: 15px; font-weight: bold; color: #ff5733;">設定標題字型：</span><br>
1. 代表意義：利用 foobar2000 的 gdi 物件建立一個用於顯示「歌曲標題」   的字型物件。
2. 參數解析：
* "Microsoft JhengHei"：字型名稱，這裡使用的是微軟正黑體。
* 18：字型大小（Pixel 像素大小）。
* 1：字型樣式（Style）。在 GDI 規範中，1代表<span style="font-weight: bold; color: #ff5733;">粗體：</span>
<br>
*在 Spider Monkey Panel 的 `gdi.Font()` 裡，最後這個參數是 **字型樣式 flags**。

>[!info] 
>常見的是：
>0 = 一般 
>1 = 粗體 
>2 = 斜體 
>4 = 底線 
>8 = 刪除線

<span style="font-size: 20px; font-weight: bold; color: #ff5733;">解析：</span><br> 

```
let font_artist = gdi.Font("Microsoft JhengHei", 13, 0);
```
</center>

<span style="font-size: 15px; font-weight: bold; color: #ff5733;">設定演出者字型：</span><br>

1. 代表意義：建立一個用於顯示「演出者（歌手/藝術家）」的字型物件。
2. 參數解析：
* "Microsoft JhengHei"：微軟正黑體。
* 13：字型大小為 13 像素（比標題小，符合主副標題的階層設計）。
* 0：字型樣式。0 代表 一般字體 (Regular / Normal)，即不粗體、不斜體。

<center>
<span style="font-size: 20px; font-weight: bold; color: #ff5733;">解析：</span><br>

```
let font_time = gdi.Font("Consolas", 16, 0);
```
</center>

<span style="font-size: 15px; font-weight: bold; color: #ff5733;">設定時間字型：</span><br>
例如: 00:03;00:42;03:17;10:25
1. 代表意義：建立一個用於顯示「播放時間（Duration/Time）」的字型物件。
2. 參數解析：
* "Consolas"：這是一款廣受歡迎的等寬字型 (Monospace)，經常用於顯示數字和程式碼。用在時間顯示上（例如 03:45），可以確保每個數字佔用的寬度一致，畫面排列時數字不會跳動。
* 16：字型大小為 16 像素。
* 0：一般字體（非粗體）。
