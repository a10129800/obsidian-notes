>[!note]
>### 為什麼不是直接寫歌曲名稱？
>因為歌曲會一直換。
>假設你播放：A 歌<br>
>`%title%` → A 歌<br>
>換成：B 歌<br>
>%title% → B 歌<br>
>
>##### 所以它其實是一個「自動取得目前歌曲資料的規則」。

```
let btn_hover = -1; // 0: prev, 1: play/pause, 2: next, 3: toggle viz, 4: playlist toggle
```
滑鼠目前懸停在哪一個按鈕上<br>
一開始：-1<br>
代表：沒有滑鼠停在任何按鈕。<br>
//後為註解btn_hover<br>
   │
   ├── -1 → 沒有按鈕<br>
   ├──  0 → 上一首<br>
   ├──  1 → 播放 / 暫停<br>
   ├──  2 → 下一首<br>
   ├──  3 → 開關 Visualization<br>
   └──  4 → 開關播放清單<br>
   例如滑鼠移到播放按鈕：btn_hover = 1;<br>
   程式就可以知道：「現在滑鼠正在 Play/Pause 按鈕上。」<br>
   然後你就可以做出 Hover 效果： ▶ ->  [ ▶ ]
